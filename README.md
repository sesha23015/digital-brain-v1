# Цифровой мозг v1

Персональная база знаний для осознанной работы с искусственным интеллектом. Учебный проект КМ1 объединяет контекст об авторе, заметки по реальным проектам, инструкции двух ИИ-ассистентов и результаты их проверки.

- [Контекст об авторе](обо%20мне.md) — опыт, проекты, инструменты и предпочтения в работе с ИИ.
- [Правила пополнения базы](правила-пополнения.md) — подготовка заметок, проверка и сохранение после подтверждения пользователя.
- [Исходный указатель материалов](index.md).

## Структура

| Папка | Содержание |

| `knowledge/` | Учебные материалы и полезные знания |

| `assistants/` | Инструкции ИИ-ассистентов |
| `tests/` | Проверки ассистентов и эксперименты с контекстом |

## Ассистенты

- [Собеседник](assistants/собеседник.md) помогает развивать идеи, задавать уточняющие вопросы и рассматривать альтернативы.
- [Критик](assistants/критик.md) проверяет аргументы, противоречия, риски и недостатки решений.

Инструкции предназначены для использования в ИИ-сервисах. Сам репозиторий не запускает ассистентов и не подключается к аккаунтам автоматически.

## Как использовать

1. Начните с итогового отчёта и выберите нужные материалы.
2. При работе с ИИ передайте ему подходящий контекст и инструкцию выбранного ассистента.
3. Проверяйте ответы: отделяйте подтверждённые факты от предположений.
4. Для новой заметки используйте команду «Сохрани в цифровой мозг» и правила пополнения базы.
5. Перед сохранением проверяйте текст и подтверждайте изменения.

Для чтения достаточно GitHub или редактора Markdown, например VS Code. Установка зависимостей не требуется. Файлы в `tests/` — текстовые отчёты, а не автоматические программные тесты.

## Статус версии

Это первая версия базы, которая будет постепенно дополняться. В итоговом отчёте отмечены ограничения: небольшое число материалов базы знаний и незавершённая самостоятельная проверка идеи сайта стоматологии. Результаты отдельных экспериментов не являются общей оценкой качества ИИ.

Репозиторий содержит личный учебный и рабочий контекст автора. Перед использованием подхода для собственной базы проверяйте, какие сведения вы готовы публиковать.
